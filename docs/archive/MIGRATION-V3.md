# Spectrum 界面与播放优化

2026-11-01。MAUI 继续使用本机 SDK 10.0.403 / MAUI 10.0.110。

## 界面与交互

- 全部交互组件改为 Adobe React Spectrum S2 1.8.2，移除 Semi Design 与 Video.js 依赖。
- 全局固定暗色、系统无衬线字体，禁用 Spectrum 的在线 Typekit 字体加载，离线时不会回退宋体。
- `src/Vroom.Client/src/theme.ts` 通过官方 `@react-spectrum/s2/style` 宏直接解析设计 token。背景使用 base / layer-1 / layer-2，文字使用 neutral / neutral-subdued，强调与反馈使用 accent / negative / positive。CSS 只引用这些 token，不维护手写色板；组件的悬停、选中、禁用和焦点状态由 Spectrum 自身管理。
- token 类安装在 html，弹窗、浮层、全屏均继承。原生启动页、图标和 Android 主题由 `scripts/sync-native-theme.mjs` 从同一包自动生成，禁止手改生成的颜色值。
- 多标签使用 Adobe React Aria Tabs 保持状态和键盘访问；复用 Spectrum token 实现有边框的格子样式、选中底色和贴边底线。顶栏空间不足时横向滚动，当前标签自动进入可见区域。图标统一由 `workspace-icons.tsx` 映射：侧栏的具体对象与组标题共用对象图标，页面入口与标签共用动作图标。筛选、排序、草稿、滚动、字幕、标注和播放列表均保留。
- 标签无间隙相接。同一具体对象的页面自动归组，组名以 10 px 字号独立放入上方 16 px 高的连续彩色横栏，下方 32 px 标签行分别保留图标和完整动作名称。标题通过 React Aria 的集合渲染器放在可选标签之外，键盘切换只经过实际标签；所有标签图标与操作按钮对齐。顶栏、选中底色和下划线使用同一组 Spectrum 彩色 token。来源类型和组内顺序见下表，相同类型的查询副本按创建顺序排列。拖动标题或任意成员移动整组，独立标签单独移动，支持边缘自动滚动和 Alt+Shift+左右键。顺序保存到现有工作区；恢复旧工作区时整理为连续组，不丢失草稿。列表播放记录来源，不随当前影片切换组。面板 DOM 顺序与标签栏排序分离，避免移动正在播放的 video 节点。
- 原“去重复核”改为“重复影片”：查找 → 按组对比 → 勾选保留项 → 保存。可播放对比、保留多个版本成组、查看并恢复隐藏影片。源文件不删除。
- 删除页面副标题和重复说明，进阶选项放进菜单或折叠区，功能保留。
- 影片列表、影片信息和全部管理页共用 `page-scroll` / `PageHeading` / `Card` 样式，删除按 TabKind 添加的 `management-panel` 以及独立覆盖。间距由 Spectrum 宏解析的 8 / 12 / 16 / 20 / 24 token 统一提供：页面左右 24 px、标题与内容及卡片之间 20 px、卡片内边距 20 px、表单项 16 px、操作控件 8 px；650 px 以下统一调整页面与卡片留白为 16 px。
- 合并网格、工具栏和底部操作区的公共声明。卡片正文通过 `bodyClassName` 应用表单布局，避免给卡片外层添加 `form-stack` 导致标题间距叠加；多张卡片纵向排列使用 `section-stack`。播放器侧栏表单也复用相同间距，视频画面继续铺满播放区。窄屏侧栏图标按钮显式提供可访问名称。
- 所有内容页使用同一个 `Page` 容器，包括全部影片、收藏、影片库、智能列表结果、管理、编辑和影片信息。标题、工具栏与正文整体最大宽度统一为 1200 px，并在可滚动区域内居中；窄窗口自动缩至可用宽度。移除影片列表的 `wide` 属性及满宽样式，宽度仅由 `.page-content` 管理。滚动及列表状态仍由外层容器维护。

标签组配色直接使用 Spectrum 的 blue / purple / cyan / orange / green / magenta visual 与 subtle-background token。根据来源键和当前组顺序确定颜色，先使用不同颜色再复用；打开、关闭和移动后自动重新分配，确保相邻组不同色，同一排序恢复后颜色一致。

### 可分组对象

分组白名单按具体对象身份判断，不按 React 页面组件类型判断。以下三类在只有一个成员时也显示带图标的组标题：

| 来源对象 | 身份 | 组标题图标 | 组内固定顺序 |
| --- | --- | --- | --- |
| 影片 | filmId | Video | 影片信息 → 播放影片 |
| 影片库 | libraryId | Folder | 影片列表 → 编辑影片库 → 播放列表 |
| 已保存的智能列表 | viewId | Filter | 影片列表 → 编辑智能列表 → 播放列表 |

组标题专用 Video / Folder / Filter，标签页按动作统一使用 InfoCircle（影片信息）、ViewList（影片列表）、Edit（编辑）、Play（播放），两套映射不重叠。独立的影片库与智能列表管理页使用 Collection / Bookmark；收藏、未看过等入口保留各自状态语义图标。

播放列表归属创建它的影片库或智能列表，不随队列当前影片变化。查询副本只有明确关联上述对象时才能加入该对象的组。

全部影片、通用浏览、收藏、未看过、已隐藏、标签关联查询、没有具体来源的临时播放列表，以及管理影片库、管理智能列表、标签与演员、重复影片、后台任务、设置、本地助手均为独立标签。未保存且没有对象 ID 的新建草稿也独立。新建或复制的通用浏览页保存各自筛选状态，不以页面标题相同作为分组依据。

标签栏移除没有明确新建对象的“+”入口，“全部影片”从侧栏打开并复用 home。恢复旧工作区时，默认值补齐后比较完整浏览状态，合并旧入口反复生成 UUID 所堆积的重复浏览页，只合并完全相同且没有未保存修改的通用页面，活动标签随之映射到保留页。不同筛选、滚动、未知扩展字段和草稿均保留。用户通过“在新标签页继续浏览”主动创建的副本带 independent 标记，保持独立。

管理页保留选中对象和表单草稿，但拥有固定的独立身份；修正旧版保存影片库后将管理页误并入影片库组、显示“编辑 1 / 编辑 2”的问题。同一对象的编辑入口复用现有编辑标签。

拖动时相邻标签按被拖动组的宽度平移让位，160 ms 过渡，拖动组跟随指针；释放或取消使用布局差值动画归位。命中计算使用未变换坐标，瞬时拖动状态通过独立上下文更新，避免 React Aria 集合缓存阻止动画更新。减少动态效果偏好下取消动画。

## 单套播放器控件

原生 video 隐藏系统控件，hls.js 只负责 HLS 媒体管线。自定义 Spectrum 控制栏提供进度、缓冲与标注、播放暂停、前后跳转、音量、速度、全屏、画中画、截图、平均帧率步进、A–B 循环、字幕和快捷键。标题与标签、信息、队列入口合并进 72 px 控制栏，取消顶部占位；侧栏包含影片标签、点/区间标注、队列与播放诊断。前后 10 秒箭头独立镜像，数字不翻转且居中。字幕支持本地 SRT/VTT，HLS 换会话时按偏移校正。

## FFmpeg 卡顿原因及处理

原链路对兼容播放一律软件重编码，并通过 `-re` 限制到实时读取，先生成的少量分片无法形成足够缓冲。跳转频繁重启转码，滚动清单删除旧片段也影响暂停后的恢复。

现按格式选择 H.264 直通封装、仅音频转换或视频转码。硬件编码器先实际编码小样确认可用，再选择 NVENC / QSV / AMF / VideoToolbox；失败回退快速软件编码。启动读取突发窗口 90 秒，随后限速为 1.25 倍，先准备 6 秒或完整短片再返回可播放地址。缓存内跳转复用会话，缓存外对齐关键帧；hls.js 在独立 worker 中解析并保留缓冲。

缓存为 EVENT 分片，保留该会话已经生成的内容，最多两个会话；关闭或超过三分钟无心跳回收。长片缓存可能接近影片大小，尚无磁盘配额和跨进程持久缓存。

## 实测

在本机 RTX 4070 / FFmpeg 9.0.2 上使用 FFmpeg 生成的 120 秒 1080p、30 fps 动态画面与音频，约 92 MB。统计服务器准备速度，不等同于浏览器首帧时间。原始结果为 `artifacts/playback-benchmark/results.json`。

| 管线 | 准备 6 秒内容耗时 | 运行 10 秒后的缓冲余量 |
| --- | ---: | ---: |
| 原软件编码 + -re | 7.664 秒 | 1.73 秒 |
| 视频直通封装 | 0.191 秒 | 92.19 秒 |
| NVENC 转码 | 0.549 秒 | 86.55 秒 |

47.3 秒跳转对齐 46 秒关键帧，首个服务分片已独立解码音视频。真实 NAS、极低速磁盘和其他 GPU 尚未进行持续播放验收，不能由本机结果推断所有设备均无卡顿。

