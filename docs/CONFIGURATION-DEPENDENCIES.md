# 配置联动与独立标注对象

## 可标注对象

声明只使用一个多选字段 `targets`。下拉框与标签列表共享 `annotation-targets.json` 中的四种图标、顺序和中英文文案。

| 选项 | 声明 ID | 标注请求中的主体 / 范围 |
| --- | --- | --- |
| 影片 | `film-whole` | `film` / `whole` |
| 标签值 | `term-whole` | `term` / `whole` |
| 影片时间点 | `film-point` | `film` / `point` |
| 影片区间 | `film-interval` | `film` / `interval` |

四项独立。例如选择标签值和影片时间点，不会额外启用整部影片。原 `targets` 与 `temporal` 的笛卡尔积无法准确表达这一组合，因此合并同时落实到公共协议、有效标注投影、写入校验、批量操作、动态表单和列表图标，而不只改变表单外观。

只接受 formatVersion 3 和上述独立 target ID；不再支持 `temporal`、旧声明读取或编辑时转换。标注记录仍采用 subject + scope。当前格式内收窄声明时，正常读取只展示有效交集，历史标注继续保留。

## 已审查并实现的级联关系

| 控制项 | 下游设置 | 界面行为 |
| --- | --- | --- |
| 可标注对象 | 适用值集合；初始化、自动更新、资料补全；显示位置 | 值集合限制仅适用于标签值；当前自动任务仅面向整部影片。不可用配置弱化并解释原因；位置候选按主体筛选。 |
| 录入/展示组件 | 控件参数、紧凑参数 | 新增参数列表跟随组件；已有的不适用参数保留并标记，切回原组件后恢复。录入与展示组件候选分别筛选。 |
| 录入组件、取值数量、数据类型 | 值约束与可枚举选项 | 提示组件和数据合同不匹配，提供关联设置入口，不自动转换或抹除既有数据类型。 |
| 数据类型 | 数字、字符串、数组、对象约束 | 仅推荐当前类型支持的约束；包括嵌套数组元素。已有不适用约束仍可查阅。 |
| 值约束的 minimum / maximum / multipleOf | 控件 min / max / step 默认值 | 明示值约束优先，并提供回到控制项的入口。 |
| 可枚举集合、编码方式 | 新选项设置、值约束 | 显示关联入口；实体引用合同不匹配时提示。选择类组件缺少集合时提示。 |
| 执行方式 | 初始化/自动更新参数 | 参数候选按常量、事实复制、表达式、正则、字典、分档匹配切换。 |
| 正则规则引用 | 内联 patterns / normalize | 选择引用后内联参数标为不参与执行，原值保留。 |
| 写入方式、取值数量 | 合并追加、来源优先级 | 单值不推荐 union；来源优先级仅在规则采用该策略时启用。 |
| 允许手动修改 | 清空后阻止自动填入 | 不允许手动修改时显示依赖原因。 |
| 新选项能力、规则写入方式 | createOptions | 要求允许新增且采用“仅建议”，提供依赖说明。 |
| 资料补全来源 | 来源字段 | 根据所选来源即时更新字段选项；失效旧值保留、不可再选，并提示重新选择。 |
| 来源传输方式 | 网络请求/限额、本地扩展名 | 网络和本地设置分别适用，原配置不删除。 |
| 来源解析格式 | HTML、XML、JSON、文本字段参数 | 选择器、提取方式、指针和正则参数随格式切换。 |
| 显示样式、分类定义、规则注册 | placement.view、facet、规则引用、事件 | 使用当前定义/公开能力的候选列表，避免自由输入不存在的引用。 |

## 交互与边界

选中控制节点后，右侧显示“关联设置”，可直接跳转或创建下游配置。不适用设置仍在结构树中，进入后展示原因和回到控制项的按钮。JSON 模式保持完整可编辑；表单不会通过删除未知字段来伪装兼容。

参数能力及依赖说明放在公开的 `editor-dependencies.json`，标签对象及图标放在 `annotation-targets.json`，属性说明沿用 `editor-guidance.json`。全部随两种宿主打包，内置 Agent 可读取同一资源。这里描述通用宿主能力，没有具体业务标签分支。

联动提示不代替发布预览和后端校验。更换控件不会自动修改数据合同或已有标注；导入的扩展参数不因编辑器尚未识别而丢失。初始化、自动更新、资料补全目前是整部影片任务，未声称支持自动生成时间片段或标签值属性。
